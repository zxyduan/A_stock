## 三、历史日线入库（本轮重点）

### 3.1 设计要点
- 表 `cn_stock_daily_kline`：`code,name,date,adjust,open,close,high,low,volume,amount,amplitude,p_change,change_amount,turnover`。
- 口径：`period=daily`、`adjust=qfq`（前复权）、区间 `20210101 → 今天`；字段映射见《历史K线入库方案与实施记录.md》。
- 解耦：直接调 `she.stock_zh_a_hist`，**不经过 `fetch_stock_hist`**，规避只读 bug；不写入上游指标/策略表。
- 幂等：主键去重 + `INSERT IGNORE`，重跑不产生重复行；断点续跑跳过 `kline_done.txt` 中的代码。

### 3.2 运行文件（宿主 `/data/instock/app/cache/`）
| 文件 | 作用 |
|---|---|
| `kline_history_loader.py` | 入库脚本（容器内 `/data/InStock/instock/cache/`） |
| `kline_history.log` | 运行输出/`ALL_DONE` 汇总行 |
| `kline_progress.txt` | 带时间戳进度（每 10 只一行） |
| `kline_done.txt` | 已成功代码（行数=完成只数） |
| `kline_failed.txt` | 失败代码 + 错误（空=无失败） |

### 3.3 规模与实测结果（2026-11-09 凌晨完成）
- 完成标志已达成：日志出现 `ALL_DONE done=1933 rows_inserted=2463313 fail=0 pool=4601`（含前序运行累计），`docker top InStock` 已无 loader 进程。
- 表内最终统计：

| 指标 | 实测值 |
|---|---|
| 总行数 `rows_cnt` | **6,091,314** |
| 覆盖只数 `codes` | **4,601**（与 `cn_stock_spot` 去重数完全一致，`missing_codes=0`） |
| 日期范围 | **2021-01-04 → 2026-11-06**（最近交易日） |
| 复权口径 | 仅 `qfq`（`adjust=qfq` 6,091,314 行） |
| 失败代码 `kline_failed.txt` | **0 行** |
| 行数分布 | 平均 1324 行/只；老票最大 1415 行；最少为 2024 年后次新股（4~37 行，属上市晚，正常） |

### 3.4 数据质量核查（`quality_check.sh`）
- **无重复**：`COUNT(*)` = `COUNT(DISTINCT code,date,adjust)` = 6,091,314，主键去重生效。
- **无缺失**：`cn_stock_spot` 去重代码对历史表 `missing_codes=0`。
- **OHLC 无空值**：`null_ohlc=0`；中文名称正常（连接需加 `--default-character-set=utf8mb4`，否则终端显示 `????`，库内不乱码），如 `600519 贵州茅台 2026-11-06 close=1453`。
- **覆盖符合上市时间**：2021-01-04 当日在表 3709 只、2024-01-02 4419 只、最新交易日 4601 只；老票全历史、次新股自上市日起。
- 中断可续：再次执行第六节启动命令即可，已完成代码自动跳过；`INSERT IGNORE` 不会产生重复。

## 四、常用可执行命令与含义（在宿主 `ssh aliyun` 后执行）

### 4.1 服务与健康
```bash
cd /data/instock && docker compose ps                 # 两容器状态/端口
docker logs --tail=100 InStock                        # 应用日志(supervisord/web/cron)
curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:9988/instock/   # Web探活(200=正常)

docker compose down && docker compose up -d           # 整体重建启动(数据在卷,不丢)
```

### 4.2 数据库
```bash
docker exec InStockDbService mariadb -uroot -proot instockdb -e "SHOW TABLES;"
docker exec InStockDbService mariadb -uroot -proot instockdb -e \
 "SELECT COUNT(*) FROM cn_stock_spot;"
docker exec InStockDbService mariadb -uroot -proot instockdb -e \
 "SELECT COUNT(*) rows_cnt,COUNT(DISTINCT code) codes,MIN(date),MAX(date) FROM cn_stock_daily_kline;"
```

### 4.3 历史入库
```bash
# 启动全量(断点续跑, 后台脱离SSH)
nohup docker exec InStock sh -c 'cd /data/InStock && PYTHONPATH=/data/InStock \
 KLINE_START=20210101 KLINE_WORKERS=10 python3 instock/cache/kline_history_loader.py \

```

## 五、遗留问题与后续（按优先级）

1. **路线B：pandas 只读就地写补丁（#8，最高优先级功能项）**
   - 现象：pandas3.1.1 CoW 强制开启，`.values[np.isnan()]=0.0` 报 `assignment destination is read-only`；共 102 处/8 文件（指标计算 93、`stockfetch.py` 2、6 个策略文件 9）。
   - 影响：`fetch_stock_hist` 可能返回 None，指标/形态/策略作业空跑、信号表为空；回测收益补算依赖先有信号。
   - 节奏：历史入库已完成、重建打断批处理的顾虑解除，可择机执行；只读挂载补丁需 `compose` 重建 app 容器，执行前确认没有其它 `docker exec` 批处理在跑即可。
   - 步骤：先补 `stockfetch.py` 两处打通历史供给 → 单票 `fetch_stock_hist` 验证 → 单票指标 → 小批 → 全市场；再改 `calculate_indicator.py` 与策略文件；盘后按 指标→形态→策略→回测 顺序跑链核表；作业 `workers` 由 40 下调至 8–16。
2. **9988 暴露与 Web 安全**：当前 Web 无认证、`debug=True`、`xsrf_cookies=False`、硬编码 `cookie_secret`；推荐本地 `ssh -L 9988:127.0.0.1:9988 aliyun` 隧道访问；若需公网访问，应在阿里云安全组做白名单 + 反向代理加 Basic Auth/HTTPS（安全组只能在控制台操作）。
3. **ETF/指数历史、周月线、hfq/不复权**：脚本预留 `KLINE_ADJUST` 与 `period` 扩展位；`fund_etf_hist_em` 个别代码映射 `KeyError` 待修。
4. **镜像空间**：`notalib-bak`（约1.5G）确认稳定后可 `docker rmi`；废弃 bullseye 镜像可清；当前可用磁盘约 28G，非紧迫。
5. **每日增量**：历史入库完成后，可加一条盘后 cron，仅抓最近若干日（`KLINE_START` 取近期）保持日线新鲜。
6. **无实盘下单能力**：上游 easytrader 绑定 Windows GUI，Linux 容器仅做数据/选股/回测。

## 六、明早一键核查（推荐先跑这个脚本）

```bash
scp 已置于服务器 /data/instock/morning_check.sh；执行：
sh /data/instock/morning_check.sh
```

判读标准：
1. `docker compose ps` 两容器 Up、DB `healthy`；Web `web_http=200`。
2. 入库无进程（已结束）；日志尾有 `ALL_DONE`；`kline_failed.txt` 为空或仅少量且可补跑。
3. `cn_stock_daily_kline` 基线：`codes=4601`、`rows≈609 万`、`min_date=2021-01-04`、`adjust` 仅 `qfq`；次日若为交易日且已跑增量，`max_date` 推进到最新交易日、`rows` 小幅增加，`codes` 不减少；`kline_failed.txt` 应为空。
4. `failed.txt` 非空时：清空对应代码的 done 记录后重跑启动命令（`INSERT IGNORE` 不重复），或单独排查该代码是否退市/停牌。
5. `free -h` 有 swap、`df -h /` 可用空间充足；备份目录最新 `*.sql.gz` 时间戳为凌晨 03:17。
