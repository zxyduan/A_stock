## 2. Web 访问方式（重要变化）

- 端口发布由 `0.0.0.0:9988:9988` 改为 **`127.0.0.1:9988:9988`**，服务器公网网卡不再监听 9988，必须经 SSH 本地隧道访问：

```bash
# 在本地电脑执行，保持窗口常开
ssh -L 9988:127.0.0.1:9988 root@139.196.74.136
# 浏览器打开
# http://localhost:9988/
```

- 已验证：`127.0.0.1:9988` 返回 200；经服务器内网/公网 IP 直连 9988 返回 000（拒绝）。
- `debug=False`：浏览器不再显示详细 traceback；错误细节看容器日志。
